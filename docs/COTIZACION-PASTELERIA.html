Implementación sobre el proyecto existente

Adaptación de la plataforma web, panel administrativo y aplicación Android para una pastelería con catálogo, personalización de productos, pedidos, pagos y seguimiento operativo.

La solución parte de una base funcional ya construida, por lo que el presupuesto contempla adaptación, pruebas y puesta en marcha; no el desarrollo desde cero.

Entregables principales

Cliente final

Menú, detalle del producto, personalización, carrito, dirección, delivery o recojo, pago, historial y seguimiento.

Operación

Panel para gestionar productos, precios, pedidos, horarios, disponibilidad y estados de preparación.

Aplicación móvil

Build Android instalable para pruebas y build de producción preparado para Google Play.

Entrega técnica

Configuración de variables, guía de uso y capacitación inicial para el personal designado.

Condiciones y exclusiones

  • Tiempo estimado: 5 a 8 semanas desde la entrega de contenidos, accesos y definiciones del negocio.
  • Incluye 30 días de corrección de defectos del alcance aprobado.
  • El dominio, hosting, servicios de mapas, proveedor de pagos, mensajería y comisiones de terceros se pagan aparte.
  • La cuenta de Google Play y su registro corresponden al cliente. La publicación requiere un AAB; el APK se usa para instalación y pruebas.
  • La emisión electrónica SUNAT/OSE, logística de terceros, diseño de logo desde cero, fotografías profesionales y versión iOS no están incluidos.
  • El tratamiento del IGV se define según la modalidad de contratación y el comprobante emitido.
Observación comercial: este importe corresponde a una implementación para un cliente. La cesión exclusiva del código fuente, la prohibición de reutilizar la base tecnológica o la venta de propiedad intelectual exclusiva requieren una adenda y una valorización adicional.
Referencia de presupuesto: si la cifra de S/ 500 era el presupuesto disponible, no alcanza para entregar este alcance completo con web, panel y APK. Ese monto podría destinarse a una maqueta o diagnóstico inicial; la adaptación funcional estimada para este proyecto es de S/ 18,000.
